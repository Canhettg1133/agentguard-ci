# Security Policy

## Supported Versions

AgentGuard-CI actively maintains and provides security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The AgentGuard-CI maintainers take security seriously. We appreciate the open-source and security research community's efforts in identifying vulnerabilities responsibly.

If you discover a security vulnerability or bypass in AgentGuard-CI:
1. **Do NOT open a public issue.**
2. Send a confidential report to: `security@agentguard.dev` or utilize GitHub's [Private Vulnerability Reporting](https://github.com/agentguard-ci/agentguard-ci/security/advisories/new).
3. Include detailed reproduction steps, example code diffs, or payload snippets demonstrating the issue.

### Our Commitment
* We will acknowledge receipt of your report within 24 hours.
* We will provide an assessment and timeline for remediation within 72 hours.
* We credit responsible security researchers in release notes upon coordinated disclosure.
